重い動画素材から軽い代役を作り、編集している間だけそちらを使うプラグインです。
プロキシの解像度もフレームレートもフレーム数も元素材と同じです。差し替えても座標や拡大率は動きません。
作成は編集している区間から順に行い、まだ作っていない区間は元素材のまま再生されます。
ファイル出力の間は必ず元素材を読みます。保存したプロジェクトも元素材を指します。

## 概要

本プラグインは AviUtl ExEdit2 の汎用プラグインとして動作します。あわせて、プロキシを読むための入力プラグインを登録します。「その他」の「プラグイン情報」には、名前を「プロキシ編集」として表示します。

4K や高ビットレートの素材は、復号そのものが重いためプレビューが実時間に追いつきません。本プラグインは、そうした素材から縮小した代役を作り、オブジェクトの参照先をそちらへ差し替えます。代役も元素材と同じ解像度として扱われるため、タイムライン上の見た目は変わりません。

作成はタイムラインで見ている位置から順に進みます。全体ができあがるのを待つ必要はありません。まだ作っていない区間は、本プラグインが Media Foundation で元素材を読んで返します。黒画にはならず、今までどおりの重さで再生されます。

## インストール方法

1. [Releases](https://github.com/routersys/AUE2-ProxyEdit/releases/latest) ページから `ProxyEdit_v1.0.0.au2pkg.zip` をダウンロードしてください。
2. AviUtl ExEdit2 を起動し、ダウンロードしたファイルをプレビュー画面へドロップします。
3. 確認の画面で「このプラグイン・スクリプトを信頼して使用する」を選んでください。インストールの後に AviUtl ExEdit2 が再起動します。

手動で配置する場合は、`ProxyEdit_v1.0.0.zip` を展開し、`ProxyEdit.aux2` を下記のフォルダーへ置いてください。次に AviUtl ExEdit2 を起動すると確認の画面が出るので、信頼して使用することを選びます。

```
C:\ProgramData\aviutl2\Plugin\
```

## 主な機能

### 1. 自動での差し替え

タイムラインへ素材を置くと、条件に合うものを自動で見つけます。そのままプロキシの作成を始め、できた分から差し替えます。既定では横幅 1921 画素以上の素材を対象にします。1920x1080 程度の軽い素材はプロキシにしても速くならないためです。幅が足りない素材でも、ビットレートが 60 Mbps 以上であれば対象になります。

手動で行う場合は「編集」メニューの「プロキシへ差し替え」と「プロキシから元素材へ戻す」を使います。

### 2. 区間ごとの作成

素材全体ではなく、既定で240フレームずつ作ります。編集している位置に近い区間から順に進みます。まだ作っていない区間は元素材を読んで返します。

### 3. 状態パネル

「表示」メニューの「プロキシ編集」で開きます。素材ごとに、作成済みの区間を帯で示し、進捗と速度と容量を表示します。行を右クリックすると、その素材を最後まで作るか、破棄するかを選べます。作成中はタスクバーのアイコンにも進捗が出ます。

AviUtl ExEdit2 が読める素材でも、本プラグインの復号が対応していない形式ではプロキシを作れません。そうした素材は名前と理由を並べて示します。作成に失敗した素材は自動で元素材へ戻すため、読めない画がタイムラインに残ることはありません。

### 4. 出力と保存の保護

ファイル出力とバッチ出力を始める前に、タイムラインを元素材へ戻します。出力は AviUtl ExEdit2 が元素材を直接読むため、画質も色も普段の出力と変わりません。出力が終わるとプロキシへ戻します。この動作を設定で切ることはできません。

プロジェクトを保存するときも同じように元素材へ戻します。保存したファイルは常に元素材を指すため、プロキシを消しても、別の環境で開いても、そのまま編集を続けられます。保存の後はプロキシへ戻すので、保存した直後でも変更ありの表示になります。

メニューを経由しない出力に備えて、入力プラグイン側にも同じ判定を置いています。出力中だと判れば、プロキシではなく元素材を読んで返します。

### 5. 保存先の管理

設定画面の「保存先を管理」で開きます。保存先にあるプロキシを、素材・状態・容量・進捗・最終使用の5列で一覧します。列見出しを押すと並べ替えられます。

プロキシを消してもタイムラインは壊れません。保存先に素材との対応を残してあるため、次に開いたときに元素材へ戻し、条件に合えば作り直します。

元素材が消えたプロキシは、使われないまま容量を占め続けます。「元素材が無いものを削除」でまとめて片付けられるほか、選んで消すこともできます。削除の前にタイムラインを元素材へ戻すため、使用中のプロキシを消してもプロジェクトは壊れません。元素材そのものは削除しません。

## メニュー項目

本プラグインは4つのメニューへ項目を追加します。

| メニュー | 項目名 | 動作 |
|---|---|---|
| 編集 | プロキシへ差し替え | 条件に合う素材をプロキシへ差し替えます |
| 編集 | プロキシから元素材へ戻す | 差し替えをすべて解除します |
| 表示 | プロキシ編集 | 状態パネルを開きます |
| 設定 | プロキシ編集 | 設定画面を開きます |

## 設定

「設定」メニューの「プロキシ編集」から変更できます。

| 項目 | 既定 | 意味 |
|---|---|---|
| 対象の素材を自動でプロキシへ差し替える | 入 | 素材を置いたときに自動で見つけて差し替えます |
| 対象にする最小の横幅 | 1921 画素 | この幅以上の素材を対象にします |
| 対象にする最小のビットレート | 60 Mbps | 幅が足りなくても、これ以上のビットレートなら対象にします |
| プロキシの解像度比率 | 50% | 元素材に対する縮小率です |
| プロキシの画質 | 80 | JPEG の品質です。30 から 98 まで指定できます |
| まとめて作る長さ | 240 フレーム | 一度に作る区間の長さです |
| 先読みに使う量 | 48 MB | 読み出しのときに先読みへ充てる量です |
| 生成の並列数 | 0 | 0 なら自動で決めます。論理コア数の半分で、最大は4です |
| 保存の上限 | 20 GB | 超えた分は最終使用の古いものから破棄します |
| プロキシの保存先 | `C:\ProgramData\aviutl2\ProxyEdit\` | 「参照...」で別のドライブへ移せます |

設定は `C:\ProgramData\aviutl2\ProxyEdit.ini` に保存されます。

## 仕組み

### 色の扱い

元素材の Y/Cb/Cr をそのまま JPEG の成分として格納し、そのまま取り出します。RGB を経由せず、色行列も範囲も仮定しません。BT.709 でも BT.601 でも、リミテッドでもフルレンジでも、元素材の値がそのまま通ります。

フルレンジの素材で確かめました。元素材の輝度は 0 から 255 まで分布し、平均は 127.25 でした。プロキシに格納された輝度も 0 から 255 までで、平均は同じく 127.25 でした。同じ大きさに揃えて比べた平均誤差は 0.06 で、これは JPEG の圧縮による損失です。

### プロキシの形式

独自の容器に、フレームごとの JPEG と索引を入れます。索引は先頭に固定長で置くため、作成しながら読むことができます。ヘッダーには元素材のパス・サイズ・更新時刻を持ち、素材が入れ替わっていれば作り直します。

保存先には `sources.txt` を置き、プロキシと元素材の対応を記録します。プロキシを消した後や容量超過で破棄した後でも、元素材へ戻せるようにするためです。

### 読み出しの経路

入力プラグインは、元素材の解像度・フレームレート・フレーム数を申告します。内部では縮小した JPEG を復号して元の大きさへ拡大して返すため、AviUtl ExEdit2 から見た素材は元と同じです。

出力形式は YUY2 です。AviUtl ExEdit2 が内部で使う形式に合わせてあるため、受け取った側での変換が要りません。縮小したフレームを元の大きさへ戻す処理は、行と列の対応表を引いて画素を並べ替えるだけです。色の変換は行いません。直前のアクセスが連番だったときだけ先読みします。

まだ作っていないフレームは Media Foundation のソフトウェア復号で元素材から読みます。AviUtl ExEdit2 のキャッシュ機能は入力プラグインの中からは呼べないため、自前の復号を使っています。

### 測定した効果

AviUtl ExEdit2 2.1.7 で、3840x2160 HEVC 10bit 39Mbps の素材を 1920x1080 のシーンに置いて測りました。値は1フレームあたりの読み出し時間です。

| 経路 | 連番 | 飛び飛び |
|---|---|---|
| 元素材 | 78.6 ms | 2087 ms |
| プロキシ | 12.9 ms | 31.1 ms |

23.976fps の素材では、1フレームに使える時間が 41.7 ms です。元素材のままでは連続再生が実時間に追いつきませんが、プロキシなら余裕があります。

1920x1080 の軽い素材では、連続再生の差はほとんどありません。飛び飛びの移動だけが速くなります。既定でこうした素材を対象にしないのはこのためです。

## 制限事項

- 本プラグインは復号に Media Foundation を使うため、Media Foundation が読めない形式は対象になりません。対象から外れた素材はエラーにならず、元素材のまま再生されます。
- 対象にするのは動画ファイルのオブジェクトだけです。シーンオブジェクトや、画像と音声だけの素材は差し替えません。
- プロキシには映像だけを入れます。音声は再生のたびに元素材から読みます。
- プロキシの容量が元素材より大きくなることがあります。フレームごとに独立した JPEG を並べる形式のためです。保存の上限を超えた分は、最終使用の古いものから破棄します。
- 素材を移動したり上書きしたりすると、そのプロキシは作り直しになります。ヘッダーに記録した元素材のパスとサイズと更新時刻のいずれかが一致しなければ、古いものとみなすためです。

## 注意事項

- プロジェクトの書き換え: 差し替えはプロジェクトのオブジェクトの参照先を書き換えます。元へ戻すには「編集」メニューの「プロキシから元素材へ戻す」を使ってください。
- 保存と出力への影響: プロジェクトを保存する直前と、出力を始める直前に、タイムラインを元素材へ戻します。保存したファイルは常に元素材を指します。終わったらプロキシへ戻すため、保存した直後でも変更ありの表示になります。
- 設定ファイル: 設定は `C:\ProgramData\aviutl2\ProxyEdit.ini` へ保存します。プロキシの実体は「プロキシの保存先」で指定した場所へ書き込みます。
- 空き容量: 保存の上限は既定で 20 GB です。保存先の空き容量を確かめてからお使いください。
- 本プラグインを使用する前に、プロジェクトファイルのバックアップを作成することを推奨します。

## ログ表示での確認

「表示」から「ログ表示」を開くと、本プラグインの状態を確認できます。本プラグインの行には `[PLUGIN] [Plugin::ProxyEdit.aux2]` が付きます。

| メッセージ | 意味 |
|---|---|
| プロキシへ差し替えました | メニューからの差し替えが終わりました。対象・差し替え・対象外の件数が続きます |
| 自動でプロキシへ差し替えました | 素材を置いたときの自動の差し替えが働きました |
| プロキシの生成を N 本の処理で開始しました | 生成を始めました。N は設定の「生成の並列数」から決まります |
| プロキシの生成が一巡しました | 対象の素材をすべて作り終えました |
| 一時的に元素材へ戻しました | 出力または保存の直前に差し替えを解除しました |
| プロキシを作れない素材が N 件あります | AviUtl ExEdit2 は読めますが、本プラグインの復号が対応していない形式です |
| 生成に失敗したので元素材へ戻しました | 作成できなかった素材を自動で元へ戻しました |
| プロキシが見つからないので元素材へ戻しました | 差し替え先が消えていたため、元素材へ戻しました |
| 容量を空けるためプロキシを破棄しました | 保存の上限を超えたため、最終使用の古いものを消しました |
