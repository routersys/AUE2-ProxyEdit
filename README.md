重い動画素材から軽い代役を作り、編集している間だけそちらを使うプラグインです。
プロキシは元素材と同じ解像度・フレームレート・フレーム数を名乗るため、差し替えても座標や拡大率は動きません。
作成は編集している区間から順に行い、まだ作っていない区間は元素材のまま再生されます。
ファイル出力の間は必ず元素材を読みます。

## 概要

本プラグインは AviUtl ExEdit2 の汎用プラグインとして動作し、あわせて入力プラグインを登録します。「その他」の「プラグイン情報」には、名前を「プロキシ編集」として表示します。

4K や高ビットレートの素材は、復号そのものが重いためプレビューが実時間に追いつきません。本プラグインは、そうした素材から縮小した代役を作り、オブジェクトの参照先をそちらへ差し替えます。代役は元素材と同じ解像度を名乗るため、タイムライン上の見た目は変わりません。

作成はタイムラインで見ている位置から順に進みます。全体ができあがるのを待つ必要はありません。まだ作っていない区間は、本プラグインが Media Foundation で元素材を読んで返すため、黒画にはならず今までどおりの重さで再生されます。

## インストール方法

1. [Releases](https://github.com/routersys/AUE2-ProxyEdit/releases/latest) ページから `ProxyEdit_v1.0.0.au2pkg.zip` をダウンロードしてください。
2. AviUtl ExEdit2 を起動し、ダウンロードしたファイルをプレビュー画面へドロップします。
3. 確認の画面で「このプラグイン・スクリプトを信頼して使用する」を選びます。

手動で置く場合は `ProxyEdit_v1.0.0.zip` を展開し、`ProxyEdit.aux2` を `C:\ProgramData\aviutl2\Plugin\` へ入れてください。

## 主な機能

### 1. 自動での差し替え

タイムラインへ素材を置くと、条件に合うものを自動で見つけてプロキシの作成を始め、できた分から差し替えます。既定では横幅 1921 画素以上の素材だけを対象にします。1920x1080 程度の軽い素材はプロキシにしても速くならないためです。

手動で行う場合は「編集」メニューの「プロキシへ差し替え」と「プロキシから元素材へ戻す」を使います。

### 2. 区間ごとの作成

素材全体ではなく、既定で240フレームずつ作ります。編集している位置に近い区間から順に進みます。まだ作っていない区間は元素材を読んで返します。

### 3. 状態パネル

「表示」メニューの「プロキシ編集」で開きます。素材ごとに、作成済みの区間を帯で示し、進捗・速度・容量を表示します。行を右クリックすると、その素材を全部作る、または破棄することができます。作成中はタスクバーのアイコンにも進捗が出ます。

本体は読めてもプロキシを作れない素材があります（対応する形式が異なるためです）。その場合は素材名と理由を並べて示します。生成に失敗した素材は自動で元素材へ戻すので、読めない画が残ることはありません。

### 4. 出力時の保護

ファイル出力を始める前に、タイムラインを元素材へ戻します。出力は本体が元素材を直接読むので、画質も色も普段の出力と変わりません。出力が終わるとプロキシへ戻します。設定で切ることはできません。

この経路で捕まえられない出力に備えて、入力プラグイン側でも `get_edit_state()` を見て元素材を返す保険を残してあります。

### 5. 保存先の管理

設定画面の「保存先を管理」で開きます。保存先にあるプロキシを、素材名・状態・容量・進捗・最終使用日時で一覧します。列見出しを押すと並べ替えられます。

元素材が消えたプロキシは誰も使わないまま容量を食い続けるので、「元素材が無いものを削除」でまとめて片付けられます。選んで消すこともできます。削除する前にタイムラインを元素材へ戻すため、使用中のものを消しても壊れません。元素材は削除しません。

## 設定

「設定」メニューの「プロキシ編集」から変更できます。

| 項目 | 既定 | 意味 |
|---|---|---|
| 対象の自動差し替え | 入 | 素材を置いたときに自動で処理するか |
| 対象にする最小の横幅 | 1921 | これ以上の幅の素材を対象にする |
| 対象にする最小のビットレート | 60 Mbps | 幅が足りなくてもこれ以上なら対象にする |
| プロキシの解像度比率 | 50% | 元素材に対する縮小率 |
| プロキシの画質 | 80 | JPEG の品質 |
| まとめて作る長さ | 240 フレーム | 一度に作る区間の長さ |
| 先読みに使う量 | 48 MB | 読み出し時に先読みへ充てる量 |
| 生成の並列数 | 0 | 0 で自動。論理コア数の半分、最大4 |
| 保存の上限 | 20 GB | 超えると古い順に破棄する |
| プロキシの保存先 | ProgramData 配下 | 別のドライブへ移せる。「参照...」で選べる |

設定は `C:\ProgramData\aviutl2\ProxyEdit.ini` に保存されます。

## 仕組み

### プロキシの形式

独自の容器に、フレームごとの JPEG と索引を入れます。索引は先頭に固定長で置くため、作成しながら読むことができます。ヘッダーには元素材のパス・サイズ・更新時刻を持ち、素材が入れ替わっていれば作り直します。

### 読み出しの経路

入力プラグインは、元素材の解像度・フレームレート・フレーム数を申告します。内部では縮小した JPEG を復号して元の大きさへ拡大して返すため、本体から見た素材は元と同じです。

出力形式は YUY2 です。本体が内部で使う形式に合わせることで、外部の入力プラグイン経由でかかる固定費を下げています。拡大と色変換はテーブルを使った自前の処理で行います。直前のアクセスが連番だったときだけ先読みします。

まだ作っていないフレームは Media Foundation のソフトウェア復号で元素材から読みます。本体のキャッシュ機能は入力プラグインの中からは呼べないため、自前の復号を使っています。

### 測定した効果

AviUtl ExEdit2 2.1.7、3840x2160 HEVC 10bit 39Mbps の素材を 1920x1080 のシーンで測った値です。1フレームあたりの読み出し時間です。

| 経路 | 連番 | 飛び飛び |
|---|---|---|
| 元素材 | 78.6 ms | 2087 ms |
| プロキシ | 12.9 ms | 31.1 ms |

実時間は 23.976fps で 41.7 ms です。元素材では連続再生が実時間に追いつきませんが、プロキシでは余裕が出ます。

1920x1080 の軽い素材では、連続再生の差はほとんどありません。飛び飛びの移動だけが速くなります。既定でこうした素材を対象にしないのはこのためです。

## 制限事項

- Media Foundation が読めない形式は対象になりません。
- プロキシの容量は元素材より大きくなります。上限を超えると古い順に破棄します。
- シーンオブジェクトや、画像・音声だけの素材は対象になりません。
- 素材を移動または上書きすると、そのプロキシは作り直しになります。
- 音声は元素材から読みます。プロキシには音声を入れません。

---

## 注意事項

差し替えはプロジェクトのオブジェクトを書き換えます。元へ戻すには「編集」メニューの「プロキシから元素材へ戻す」を使ってください。プロキシを含んだままプロジェクトを保存しても、出力は元素材で行われます。

プロキシの保存先の空き容量にご注意ください。既定の上限は 20 GB です。

## ログ表示での確認

「表示」の「ログ表示」に `[PLUGIN] [Plugin::ProxyEdit.aux2]` として出ます。プロキシの登録、差し替えた件数、生成の失敗が記録されます。
